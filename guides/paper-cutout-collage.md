# 종이 오리기(페이퍼 컷아웃) 콜라주 영상 만들기

레퍼런스 영상의 **연출 구조만** 빌려 오고, 등장하는 소재는 내 주제로 바꿔 종이 오리기 느낌의 콜라주 애니메이션을 만드는 방법입니다.
Claude Opus 5.5가 연출 분석, 장면표 작성, 이미지 합성, 움직임, 장면 전환, 음악까지 코드로 처리하고, 배경과 소품 이미지는 GPT Image로 만듭니다.

## 한눈에 보기

| 단계 | 하는 일 | 도구 | 결과물 |
|---|---|---|---|
| 1 | 레퍼런스 영상 고르기 | Pinterest | 레퍼런스 영상 1~2편 |
| 2 | 연출 분석 | Claude | 연출 분석표 |
| 3 | 소재 바꾼 장면표 작성 | Claude | 장면표(샷 리스트) |
| 4 | 배경·소품 이미지 생성 | GPT Image | 배경 PNG, 투명 소품 PNG |
| 5 | 코드로 합성해 영상 완성 | Claude (HTML/Canvas, Remotion 등) | MP4 |
| 6 | 종이 질감 마감 | Claude | 흰 테두리 + 그림자 적용본 |
| 7 | 레퍼런스와 수치 비교 | Claude + ffmpeg | 비교표, 수정 목록 |
| 8 | 로고·브랜드 제거 확인 | 직접 점검 | 공개 가능한 최종본 |

---

## 1. 레퍼런스 고르기

Pinterest에서 아래 검색어로 찾습니다.

- `paper cutout animation`
- `collage animation`
- 범위를 좁힐 때: `stop motion paper collage`, `cut paper motion design`, `mixed media collage animation`

고를 때 볼 점:

- 10~30초 분량으로 장면이 4~8개쯤 되는 영상이 분석하기 좋습니다.
- 움직임이 매끄럽지 않고 **뚝뚝 끊기는(스톱모션)** 영상을 고르면 종이 느낌이 잘 삽니다.
- 로고, 브랜드 문구, 인물 얼굴이 많은 영상은 피합니다. 쓰더라도 연출만 가져옵니다(8단계).

## 2. 연출 분석 요청

영상 파일(또는 프레임 캡처)을 Claude에게 주고 아래처럼 요청합니다.

```text
첨부한 영상은 종이 오리기 콜라주 애니메이션 레퍼런스야. 내용 말고 연출만 분석해 줘.
아래 항목을 표로 정리해 줘.

1. 장면 구성: 장면 번호, 시작~끝 시간(초), 화면에 나오는 요소, 화면 배치(전경/중경/배경)
2. 전환 방식: 장면이 바뀔 때 쓰는 기법(종이 넘김, 찢기, 밀어내기, 컷, 가림막 등)과 길이(초)
3. 움직임 리듬: 초당 몇 장으로 끊기는지(예: 12fps, 8fps), 물체가 들어오고 나가는 방식, 흔들림(지글거림) 정도
4. 종이 질감: 종이 종류(크라프트지, 신문지, 색지 등), 테두리 처리, 그림자 방향과 깊이, 구김·결
5. 색감: 주요 색 5개(HEX), 채도·명도 경향, 배경색
6. 음악 템포: BPM, 박자에 맞춰 움직이는 지점, 효과음 사용 여부

마지막에 이 영상 연출의 핵심 규칙을 5줄로 요약해 줘.
```

## 3. 소재만 바꾼 장면표 만들기

연출 구조(장면 수, 시간, 전환, 리듬, 색감 규칙)는 그대로 두고 **등장하는 소재만** 내 주제로 바꿉니다.

```text
방금 분석한 연출 구조는 그대로 유지하고, 등장하는 소재만 [내 주제]로 바꾼 장면표를 만들어 줘.

- 장면 수, 장면별 길이, 전환 방식, 움직임 리듬, 음악 BPM은 바꾸지 마.
- 장면마다 필요한 배경 1장과 오려낸 소품 목록을 적어 줘.
- 소품마다 GPT Image에 넣을 영어 프롬프트도 함께 써 줘.
- 표 열: 장면 / 시간 / 화면 설명 / 배경 / 소품 / 움직임 / 전환 / 자막
```

장면표 예시(주제: "AI와 함께하는 미래 교실"):

| 장면 | 시간 | 화면 설명 | 배경 | 소품 | 움직임 | 전환 |
|---|---|---|---|---|---|---|
| 1 | 0.0–3.0초 | 빈 교실에 칠판이 내려옴 | 크라프트지 교실 벽 | 칠판, 책상 3개 | 위에서 툭 떨어진 뒤 2번 튕김 | 종이 넘김 0.5초 |
| 2 | 3.0–6.5초 | 학생 실루엣이 태블릿을 듦 | 하늘색 색지 | 학생 2명, 태블릿, 말풍선 | 8fps로 좌우 흔들림 | 찢기 0.4초 |
| 3 | 6.5–10.0초 | 아이디어 전구가 켜지고 별이 퍼짐 | 남색 색지 | 전구, 별 6개, 연필 | 박자마다 별 하나씩 등장 | 밀어내기 0.3초 |
| 4 | 10.0–13.0초 | 학교 건물과 제목 문구 | 신문지 질감 하늘 | 학교 건물, 구름 2개, 제목 띠지 | 제목이 한 글자씩 붙음 | 끝 |

## 4. 배경과 소품 이미지 만들기 (GPT Image)

배경과 소품을 **따로** 만들어야 나중에 코드로 움직일 수 있습니다.

배경 프롬프트 예시:

```text
Flat paper collage background, kraft paper texture with visible fibers and subtle wrinkles,
classroom wall scene, muted warm palette (#C9A27E, #F2E6D0, #6B8F9C), no text, no logo,
16:9, even lighting, no objects in the center
```

소품 프롬프트 예시:

```text
Single cut-out paper prop of a green chalkboard, handmade construction paper look,
slightly uneven scissor-cut edges, flat front view, transparent background, no shadow,
no text, no logo
```

- 소품은 **투명 배경(PNG)** 으로 받습니다. 투명 배경이 안 나오면 배경 제거 도구로 지운 뒤 씁니다.
- 그림자와 흰 테두리는 이미지에 넣지 말고 6단계에서 코드로 넣습니다. 그래야 장면마다 그림자 방향을 맞출 수 있습니다.
- 파일 이름은 장면표와 맞춥니다. 예: `s1_bg.png`, `s1_chalkboard.png`, `s2_student_a.png`

## 5. 코드로 합성해 영상 완성

이미지를 폴더에 넣고 Claude에게 요청합니다.

```text
assets/ 폴더의 배경과 소품 이미지로 장면표대로 영상을 만들어 줘.

- 1920x1080, 30fps로 렌더링하되 소품 움직임은 [2단계에서 나온 값, 예: 8fps]로 끊어서 스톱모션처럼 보이게 해 줘.
- 소품은 위치·회전에 아주 작은 무작위 흔들림(±1~2px, ±1도)을 프레임마다 줘서 손으로 옮긴 느낌을 내 줘.
- 전환은 장면표에 적은 방식과 길이를 그대로 지켜 줘.
- 배경음악은 [BPM]에 맞춰 주요 움직임이 박자에 떨어지게 해 줘. 음원은 저작권 문제 없는 것으로 쓰고 출처를 남겨 줘.
- HTML/Canvas로 만들고 MP4로 녹화하거나, Remotion으로 렌더링해 줘.
```

스톱모션 리듬을 내는 핵심은 시간을 계단처럼 끊는 것입니다.

```js
// 30fps 영상에서 소품은 8fps로만 움직이게 하기
const STEP_FPS = 8;
function steppedTime(t) {
  return Math.floor(t * STEP_FPS) / STEP_FPS;
}

// 프레임마다 같은 값이 나오는 흔들림 (같은 계단 안에서는 고정)
function jitter(seed, t, amount) {
  const k = Math.floor(t * STEP_FPS);
  const x = Math.sin(seed * 12.9898 + k * 78.233) * 43758.5453;
  return (x - Math.floor(x) - 0.5) * 2 * amount;
}
```

## 6. 종이를 오려 붙인 느낌 살리기

소품마다 **흰 테두리 + 그림자**를 더하면 가위로 오려 붙인 느낌이 납니다.

CSS로 할 때:

```css
.cutout {
  filter:
    /* 흰 테두리: 사방으로 흰 그림자를 겹쳐 두께를 만듦 */
    drop-shadow(3px 0 0 #fff) drop-shadow(-3px 0 0 #fff)
    drop-shadow(0 3px 0 #fff) drop-shadow(0 -3px 0 #fff)
    /* 바닥에 붙은 종이 그림자: 짧고 진하게 */
    drop-shadow(2px 3px 1px rgba(0, 0, 0, 0.25))
    /* 살짝 떠 있는 그림자: 넓고 옅게 */
    drop-shadow(6px 10px 12px rgba(0, 0, 0, 0.18));
}
```

Canvas로 할 때는 소품 알파 채널을 바깥으로 3~6px 넓힌 흰 실루엣을 먼저 그리고, 그 아래에 그림자를 깔고, 맨 위에 소품을 그립니다.

추가로 질감을 살리는 방법:

- 화면 전체에 종이결 이미지를 `multiply`로 아주 옅게(불투명도 10~20%) 덮습니다.
- 그림자 방향은 모든 장면에서 같은 쪽(예: 오른쪽 아래)으로 통일합니다.
- 소품이 떨어져 붙는 순간 그림자를 넓게 → 좁게 줄이면 "착" 붙는 느낌이 납니다.

## 7. 레퍼런스와 수치로 비교하기

완성본과 레퍼런스를 **같은 기준**으로 재 달라고 하면 어디가 다른지 숫자로 나와 고칠 곳이 분명해집니다.

```text
레퍼런스 영상과 완성본을 같은 기준으로 비교해서 표로 보여 줘.
항목: 전체 길이, 장면 수, 평균 장면 길이, 장면 전환 횟수와 평균 길이,
움직임 끊김(fps), 주요 색 5개와 평균 채도·명도, 음악 BPM, 박자에 맞춘 동작 비율.
차이가 큰 순서로 정렬하고, 항목마다 고칠 방법을 한 줄로 적어 줘.
```

직접 재 볼 때 쓸 수 있는 명령어:

```bash
# 장면 전환 시점 찾기 (값이 클수록 큰 변화만 잡음)
ffmpeg -i video.mp4 -vf "select='gt(scene,0.3)',showinfo" -f null - 2>&1 | grep pts_time

# 전체 길이(초)
ffprobe -v error -show_entries format=duration -of csv=p=0 video.mp4

# 1초에 한 장씩 프레임 뽑기 (색감 비교용)
ffmpeg -i video.mp4 -vf fps=1 frames/%03d.png
```

비교표 예시:

| 항목 | 레퍼런스 | 완성본 | 차이 | 고칠 방법 |
|---|---|---|---|---|
| 평균 장면 길이 | 2.8초 | 3.6초 | +0.8초 | 장면 3·4를 0.5초씩 줄이기 |
| 움직임 끊김 | 8fps | 12fps | +4fps | `STEP_FPS`를 8로 낮추기 |
| 평균 채도 | 38% | 52% | +14%p | 소품 색을 한 단계 탁하게 |
| 음악 BPM | 96 | 110 | +14 | 96BPM 음원으로 바꾸기 |

## 8. 로고·브랜드 문구는 빼기

- 레퍼런스에서는 **연출(구조, 리듬, 전환, 질감 규칙)만** 가져옵니다.
- 레퍼런스에 나온 로고, 브랜드 이름, 슬로건, 캐릭터, 특정 그림은 그대로 옮기지 않습니다.
- 이미지 프롬프트에는 `no text, no logo`를 넣고, 완성본도 한 번 더 확인합니다.
- 음악·폰트·종이결 이미지도 사용 허락 범위를 확인하고, 출처를 영상 설명란에 적습니다.

## 마무리 점검표

- [ ] 장면 수와 장면별 길이가 레퍼런스 분석표와 맞는가
- [ ] 소품 움직임이 계단식으로 끊기고, 흔들림이 있는가
- [ ] 모든 소품에 흰 테두리와 같은 방향의 그림자가 있는가
- [ ] 주요 동작이 음악 박자에 떨어지는가
- [ ] 레퍼런스와의 수치 비교에서 큰 차이가 남아 있지 않은가
- [ ] 로고, 브랜드 문구, 저작권이 불분명한 소재가 없는가
